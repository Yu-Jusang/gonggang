# gonggang → kkongbap

‘공강에 뭐먹지’(https://yu-jusang.github.io/gonggang/)는 2026-11-03 이름을 ‘꽁밥’으로 바꾸고 https://yu-jusang.github.io/kkongbap/ 으로 옮겼다.

이 저장소는 예전 주소로 들어온 방문자를 새 주소로 넘기는 안내 페이지만 담는다. `/gonggang/` 뒤의 경로·검색어·해시(예: `#event/<id>`)는 그대로 새 주소에 붙는다. 없는 하위 경로는 `404.html`이 같은 방식으로 넘긴다.

사이트 코드와 자료: https://github.com/Yu-Jusang/kkongbap
